Blackbox Exporter Prometheus Queries
=====================================

Blackbox exporter doesn't expose a _count metric. Use these queries to count requests:

Count TOTAL requests per URL (success + failure) - last hour:
count_over_time(probe_success{job="blackbox"}[1h])

Count SUCCESSFUL requests per URL - last hour:
sum_over_time(probe_success{job="blackbox"}[1h])

Count FAILED requests per URL - last hour:
count_over_time(probe_success{job="blackbox"}[1h]) - sum_over_time(probe_success{job="blackbox"}[1h])

Count total requests across all URLs:
sum(count_over_time(probe_success{job="blackbox"}[1h]))

Count requests per URL (last 24 hours):
count_over_time(probe_success{job="blackbox"}[24h])

Request rate (requests per minute):
count_over_time(probe_success{job="blackbox"}[1m])

List all available blackbox metrics:
{job="blackbox"}

=====================================
View ALL Endpoints Separately (Use this in Grafana Table/Graph)
=====================================

# Shows each endpoint with its total request count (success + failure):
count_over_time(probe_success{job="blackbox"}[1h])

# Shows each endpoint with successful request count:
sum_over_time(probe_success{job="blackbox"}[1h])

# Shows each endpoint with failed request count:
count_over_time(probe_success{job="blackbox"}[1h]) - sum_over_time(probe_success{job="blackbox"}[1h])

# Success rate percentage per endpoint:
(sum_over_time(probe_success{job="blackbox"}[1h]) / count_over_time(probe_success{job="blackbox"}[1h])) * 100
